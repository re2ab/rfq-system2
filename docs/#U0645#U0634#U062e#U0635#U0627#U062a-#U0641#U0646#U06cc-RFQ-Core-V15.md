# مشخصات فنی سیستم مدیریت درخواست خرید صنعتی
## RFQ-Core — نسخه ۱۵ (نهایی تأییدشده)

**تاریخ:** ۱۴۰۵/۰۵/۲۷ (۱۸ اوت ۲۰۲۶)  
**نوع سند:** مشخصات فنی و عملکردی به‌روز  
**وضعیت:** منطبق با پیاده‌سازی فعلی و موارد تأییدشده در جلسات طراحی

---

## ۱. خلاصه محصول

سیستم تحت وب **RFQ-Core** برای مدیریت چرخه درخواست خرید صنعتی (RFQ)، پیگیری پرونده‌ها در پایپ‌لاین، مخاطبان و سازمان‌ها، وظایف، اسناد خروجی، ایمیل، گزارش‌گیری و تنظیمات ماژولار طراحی شده است.

- **استک:** Laravel 11، PHP 8.2+ (توصیه ۸.۴)، Blade، Tailwind CDN، Spatie Permission، Morilog Jalali  
- **UI:** چیدمان شبیه Salesforce Lightning + هویت بصری الهام‌گرفته از Shiftaam (فیروزه‌ای `#0f766e`)، فونت Vazirmatn، آیکون SVG سبک Lucide  
- **زبان رابط:** فارسی (RTL)، تقویم و اعداد شمسی در بخش‌های کلیدی  
- **احراز هویت:** فقط ایجاد حساب توسط مدیر/ادمین؛ بدون ثبت‌نام عمومی

---

## ۲. نقش‌ها و دسترسی‌ها (RBAC)

| نقش | توضیح دسترسی اصلی |
|-----|-------------------|
| **admin** | تمام دسترسی‌ها؛ ایجاد مدیر؛ حذف مخاطب؛ تنظیمات کامل |
| **technical_manager / financial_manager** | داشبورد، گزارش‌ها، ایجاد وظیفه، مشاهده یادداشت محرمانه مخاطب |
| **expert** (کارشناس) | ترکیب دسترسی فنی و مالی کارشناس |
| **technical_expert / financial_expert** | کار روی پرونده‌ها، مخاطبان، وظایف محول‌شده |

### قواعد تأییدشده
- دسترسی **تنظیمات** فقط ادمین  
- **گزارشات** و **داشبورد** فقط مدیران و ادمین  
- **ایجاد وظیفه** فقط مدیران و ادمین  
- کارشناس: وظایف تیمی/همگانی را می‌بیند و انجام می‌دهد؛ وظیفه اختصاصی دیگران را نمی‌بیند؛ ایجاد وظیفه ندارد  
- ایجاد کاربر جدید: انتخاب نقش توسط مدیر؛ فقط ادمین اصلی می‌تواند حساب مدیر بسازد

## ۳. معماری منوی کناری (RTL — سمت راست)

منوی تمام‌قد صفحه (از لبه بالا تا پایین)، قابل جمع/باز:

| آیتم | ماژول / شرط |
|------|-------------|
| داشبورد | `dashboard.view` |
| مخاطبان / سازمان‌ها | ماژول contacts |
| پرونده‌ها | — |
| پایپ‌لاین (کانبان) | ماژول kanban |
| وظایف / تقویم | ماژول tasks |
| اسناد | ماژول documents |
| ایمیل | ماژول email |
| گزارش‌ها | `report.view` + ماژول reports |
| پروفایل | — |
| تنظیمات | `settings.manage` |

- حالت جمع: فقط آیکون؛ حالت باز: آیکون + عنوان (عرض حدود ۲۲۰px)  
- لوگو و نام شرکت در **هدر کنار جستجو** (نه بالای منو)  
- موبایل: منوی همبرگری؛ آواتار با دراپ‌داون (پروفایل، اعلان، تنظیمات، خروج)

## ۴. ماژول‌ها و قابلیت‌ها

### ۴.۱ پرونده‌ها و پایپ‌لاین (هسته)
- فهرست پرونده، ایجاد/ویرایش/نمایش  
- **کانبان با Drag & Drop** بین وضعیت‌ها  
- تایم‌لاین فعالیت‌ها: یادداشت، **گزارش تماس تلفنی** (متمایز از کامنت عادی) با تاریخ/ساعت  
- منشن کاربران، لایک/واکنش، کامنت تو در تو، ایموجی  
- پیوست تا ۵۰MB: Word، PDF، تصویر، ZIP  
- وضعیت‌ها و ماشین حالت پرونده  
- تحویل (Delivery) و مطالبات/پرداخت (Receivable)  
- چندارزی: قیمت تامین‌کننده معمولاً EUR؛ قیمت‌دهی EUR یا IRR  
- VAT: ترم CPT/CFR بدون ارزش‌افزوده؛ ترم DDP با ۱۰٪ VAT  

### ۴.۲ مخاطبان و سازمان‌ها
- کارت مخاطب: عنوان، سمت، تصویر، تب اطلاعات تماس (قابل کپی)، تب مرتبط‌ها (ایمیل‌ها، نکات، پرونده‌های فعال، گزارش تماس)  
- **یادداشت محرمانه** مخاطب (فقط مدیران/ادمین)  
- فیلدهای سفارشی قابل تعریف توسط مدیر  
- فیلدهای پایه: تلفن، تلفن۲، موبایل، فکس، ایمیل، توضیحات  
- نوع سازمان با برچسب فارسی (مشتری / تامین‌کننده / هر دو)  
- **ایمپورت CSV** (خروجی Excel) و **اکسپورت CSV** دفترچه مخاطبان  
- حذف مخاطب فقط ادمین  

### ۴.۳ وظایف
- واگذاری به کارشناس درباره پرونده یا مخاطب  
- مهلت، اولویت و وضعیت با برچسب فارسی  
- چک‌لیست  
- بدون تکرار شونده در این فاز  
- نمایش در داشبورد مدیریتی  

### ۴.۴ تقویم
- شمسی، شروع هفته از شنبه، جمعه با رنگ قرمز روشن (تعطیل)، اعداد فارسی  

### ۴.۵ اسناد و قالب‌ها
- قالب پیشنهاد فنی، مالی، فاکتور با سربرگ/فوتر شرکتی و Placeholder  
- قالب ایمیل با امضای فوتر  
- دو حساب ایمیل شرکتی: داخلی (مشتری) و خارجی (سازنده)  
- نسخه‌بندی / بازبینی سند  

### ۴.۶ ایمیل
- فهرست، ارسال، شبیه‌ساز ورود IMAP دستی  
- لینک خودکار به پرونده با شماره CASE در موضوع  

### ۴.۷ گزارش‌ها
- پایپ‌لاین، عملکرد کارشناسان، وظایف، Aging مطالبات  
- **گزارش اختصاصی** با criteria، ذخیره و حذف  

### ۴.۸ داشبورد
- KPI: پرونده باز، نرخ برد، کل، متوقف  
- نوار/مسیر وضعیت‌ها  
- آخرین پرونده‌ها و وظایف من  

### ۴.۹ تنظیمات (ادمین)
- ماژول‌ها: فعال/غیرفعال (ایمیل، وظایف، کانبان، …)  
- کاربران و نقش‌ها  
- قالب‌ها و پیش‌نمایش  
- ظاهر: تم روشن/تیره، رنگ برند، لوگو و نام شرکت  
- فیلدهای سفارشی  
- پشتیبان‌گیری رمزنگاری‌شده، زمان‌بندی، ایمپورت  
- احراز هویت دو مرحله‌ای (زیرساخت)  

### ۴.۱۰ جستجو
- جستجوی سراسری و جستجو داخل بخش (پرونده، کامنت، مخاطب، سازمان، اسناد)  

### ۴.۱۱ پروفایل
- نام و عکس توسط کاربر؛ ایمیل و رمز فقط با اجازه مدیر

```

```

## ۷. نصب سریع

1. `composer install`  
2. کپی `.env.example` → `.env` و `php artisan key:generate`  
3. SQLite: `touch database/database.sqlite` یا تنظیم MySQL  
4. `php artisan migrate --force && php artisan db:seed --force`  
5. `php artisan storage:link && php artisan serve --host=0.0.0.0 --port=8000`  

**ورود پیش‌فرض پس از Seed:**  
`admin@example.com` / `password`

جزئیات بیشتر: `docs/02-راهنمای-نصب-قدم‌به‌قدم.md` و `INSTALL.md`
