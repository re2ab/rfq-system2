# فاز D — ادغام با پرونده و مخاطب

نسخه: 19.11.0

## قابلیت‌ها
- پیشنهاد تطبیق Contact / Organization / شماره پرونده روی پیام انتخاب‌شده
- لینک دستی ایمیل به پرونده و مخاطب
- برداشتن لینک پرونده
- تب «ایمیل‌ها» در صفحه پرونده با تایم‌لاین ورودی/خروجی
- ارسال ایمیل از صفحه پرونده (compose با case_id)
- کلیک روی ایمیل مخاطب → Compose با گیرنده
- گزارش ایمیل‌های بدون پرونده: `/mail/unmatched`

## نصب
```bash
php artisan route:clear && php artisan view:clear
# migration جدید لازم نیست اگر فاز A/B/C نصب است
```
